# 작업 이어가기

지난 세션의 기록을 불러와 바로 작업을 재개합니다.

## 절차

### 1. 기록을 읽는다

`D:\gg\.claude\worklog\STATE.md`를 Read로 읽습니다.

**파일이 없으면**: 저장된 기록이 없다고 알리고, `D:\gg\CLAUDE.md`와 최근 수정된 파일로 현재 상태를 파악한 뒤 무엇을 할지 물어봅니다. 여기서 멈추세요 — 없는 기록을 지어내지 마세요.

### 2. 기록이 아직 맞는지 확인한다

STATE.md는 저장 당시의 사실입니다. 그 사이 파일이 바뀌었을 수 있으니 검증하세요.

```powershell
Get-ChildItem D:\gg -Recurse -File |
  Where-Object { $_.FullName -notmatch '\\\.claude\\worklog\\' } |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 10 @{n='파일';e={$_.FullName.Replace('D:\gg\','')}}, LastWriteTime |
  Format-Table -AutoSize
```

- STATE.md의 "마지막 저장" 시각보다 **나중에** 수정된 파일이 있으면, 기록 밖에서 변경이 일어난 것입니다. 해당 파일을 확인하고 차이를 사용자에게 알리세요.
- "지금 건드리고 있는 곳"에 적힌 `파일:줄` 위치를 실제로 읽어 내용이 맞는지 확인합니다. 단일 파일 앱이라 줄 번호는 잘 밀립니다 — 안 맞으면 주변 구분선 제목(`/* ══ 제목 ══ */`)으로 다시 찾으세요.

### 3. 짧게 브리핑한다

한국어로, 아래만 간결하게 전달합니다. STATE.md 전문을 그대로 붙여넣지 마세요.

- **지난 작업**: 한 줄 요약
- **다음 할 일**: 체크 안 된 항목들 (그대로 나열)
- **막힌 것**: 있으면 함께
- **달라진 점**: 2번에서 발견한 불일치가 있으면

### 4. 바로 이어간다

"다음에 할 일"이 하나로 명확하면 확인을 기다리지 말고 **그 작업을 시작하세요**. 사용자는 이어서 하려고 이 스킬을 부른 것입니다.

여러 갈래라 우선순위가 갈리거나, 3번에서 기록과 실제가 어긋났다면 그때만 무엇부터 할지 물어봅니다.

## 참고

- 더 이전 기록은 `.claude/worklog/history/` 안에 `YYYYMMDD-HHmm.md`로 쌓여 있습니다. "그 전에 뭐 했지?" 같은 질문에는 여기를 보세요.
- 세션을 마칠 때는 `/save-work`로 갱신하도록 안내하세요.
