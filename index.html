    글결 사용 설명

    이 앱이 뭐예요?

    외국어로 된 소설을 한국어로 바꿔주는 앱이에요. 일본어든 영어든, 무슨 언어인지 몰라도 그냥 붙여넣으면 알아서 알아보고 번역해 줍니다.

    번역한 글은 서재에 쌓이고, 모르는 단어는 단어장에 모아둘 수 있어요.

    API 키가 뭐예요?

    번역을 실제로 해주는 건 구글의 인공지능이에요. 이 앱은 "이거 번역해 줘"라고 부탁을 전달하는 심부름꾼일 뿐입니다.

    구글 입장에서는 누가 부탁하는 건지 알아야겠죠. 그래서 내 이름표를 하나 받아와야 해요. 그게 API 키입니다.

    도서관 회원증 같은 거예요. 회원증이 있어야 책을 빌리듯, 이 키가 있어야 번역을 부탁할 수 있어요. 한 번 받아두면 계속 씁니다.

    AIza로 시작하는 길쭉한 영어·숫자 뭉치예요.

    키를 어떻게 받아요? (3분)
    1. aistudio.google.com/apikey 를 누르세요.
    2. 구글 계정으로 로그인해요. 평소 쓰는 지메일 계정이면 됩니다.
    3. Create API key 버튼을 누르세요.
    4. AIza…로 시작하는 글자를 복사하세요.
    5. 앱의 설정을 열어 그 칸에 붙여넣기 하면 끝이에요.

    넣는 순간 저절로 저장돼요. 다음에 앱을 켜면 이미 들어가 있습니다.

    돈이 드나요?

    무료예요. 카드를 등록하지 않아도 되고, 자동으로 돈이 빠져나가지도 않아요.

    대신 하루에 쓸 수 있는 양이 정해져 있어요. 다 쓰면 "한도에 걸렸어요"라고 뜹니다. 잠시 쉬었다 하거나 다음 날 하시면 돼요.

    키를 넣어도 안전한가요?

    네. 키는 지금 쓰는 이 기기 안에만 저장돼요. 다른 누구에게도 전송되지 않습니다.

    다만 남에게 키를 알려주지는 마세요. 회원증을 빌려주는 것과 같아서, 남이 내 몫을 대신 써버릴 수 있어요. 실수로 알려줬다면 위 사이트에서 그 키를 지우고 새로 만들면 됩니다.

    어떻게 쓰는 건가요?
    1. 제목 칸에 작품 이름을 적어요. (안 적어도 괜찮아요)
    2. 본문 칸에 외국어 소설을 붙여넣어요.
    3. 번역하기를 누르고 기다려요.

    글이 아주 길어도 괜찮아요. 앱이 알아서 여러 조각으로 나눠 번역한 뒤 이어붙입니다.

    글자 크기·색·글꼴은 오른쪽 위 가a 버튼에서 바꿀 수 있어요.

    번역문이 한 줄씩 나타나요. 고장인가요?

    정상이에요. 인공지능은 글을 한꺼번에 완성하지 않고 앞에서부터 한 글자씩 써 내려갑니다. 사람이 글을 쓰는 것과 비슷해요.

    이 앱은 다 쓸 때까지 기다리지 않고 써지는 대로 바로 보여줍니다. 그래서 문장이 조금씩 늘어나고, 끝에 깜빡이는 막대(▍)가 따라다녀요.

    막대가 깜빡이는 동안은 아직 쓰는 중이에요. 다 쓰면 막대가 사라지고, 각주 번호가 붙은 정식 화면으로 바뀝니다.

    중간에 글이 어색해 보여도 걱정 마세요. 문장이 끝까지 안 써진 상태라 그렇게 보이는 것뿐이에요.

    화면 오른쪽에 흐른 시간이 나옵니다. 너무 오래 걸리면 설정에서 번역 속도를 빠르게로 두거나, 모델을 flash-lite로 바꿔 보세요.

    링크로 가져오기 · 어떤 링크가 되나요?

    소설이 올라온 페이지 주소를 넣으면, 인공지능이 그 페이지를 읽어 본문을 채워줍니다. 이때도 번역은 하지 않아요. 원문을 가져오기만 합니다.

    솔직히 말씀드리면 안 되는 곳이 더 많아요. 되면 편하고, 안 되면 본문을 복사해 붙여넣는 게 확실합니다.

    대체로 되는 곳 — 로그인 없이 바로 글이 보이는 블로그, 공개 게시판, 위키 같은 곳

    대체로 안 되는 곳

    1. 로그인해야 보이는 곳 (픽시브, 비공개 작품 등)
    2. 앱으로만 볼 수 있는 곳
    3. 연령 확인이 필요한 곳
    4. 주소를 눌러야 본문이 나타나는 곳

    가져오기가 실패하면 이 링크는 읽지 못했어요라고 알려드려요. 그때는 본문을 직접 복사해서 붙여넣어 주세요.

    가져왔더라도 꼭 확인하세요. 인공지능이 긴 글을 중간에 줄이거나 뒷부분을 빠뜨리는 일이 있어요. 글자 수를 보고 원래 분량과 비슷한지 확인한 뒤 번역하시는 걸 권합니다.

    깃허브로 폰과 컴퓨터 잇기
    1. 깃허브에서 비공개(Private) 저장소를 하나 만드세요. (예: geulgyeol-data)
    2. Settings → Developer settings → Personal access tokens → Fine-grained tokens 로 갑니다.
    3. Generate new token → Repository access에서 방금 만든 저장소 하나만 고릅니다.
    4. Permissions에서 Contents를 Read and write로 바꿉니다.
    5. 만들어진 토큰을 복사해 설정의 깃허브 칸에 붙여넣으세요.
    꼭 저장소 하나에만 권한을 주세요. 그래야 토큰을 잃어버려도 피해가 없어요.

    컴퓨터에서 올리기, 폰에서 내려받기 하면 서재·단어장·설정이 통째로 옮겨갑니다.

    오류가 떠요

    "API 키가 올바르지 않아요" — 복사할 때 앞뒤 빈칸이 딸려왔을 수 있어요. 지우고 다시 붙여넣어 보세요.

    "인터넷 연결에 실패했어요" — 광고 차단 프로그램이 막고 있을 수 있어요. 잠시 꺼보세요.

    "모델을 쓸 수 없어요" — 구글이 그 모델을 없앤 거예요. 설정에서 목록 새로고침을 누르면 지금 쓸 수 있는 것만 다시 담아옵니다.

    "한도에 걸렸어요" — 오늘 몫을 다 썼어요. 1~2분 뒤나 내일 이어서 하세요.

    "이 링크는 읽지 못했어요" — 위 링크로 가져오기 항목을 봐주세요.
